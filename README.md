# Copy Value Visual for Power BI

Power BI レポート上でテーブルビジュアルの選択行の値を、ボタン一発でクリップボードにコピーできるカスタムビジュアルです。

## ダウンロード

**[⬇ 最新の .pbiviz ファイルをダウンロード](https://github.com/mintiasaikoh/powerbi-copy-value-visual/releases/latest)**

## インストール手順

1. 上記リンクから `.pbiviz` ファイルをダウンロード
2. Power BI Desktop を開く
3. 「視覚化」ペイン → 「`...`」→「**ファイルからビジュアルをインポート**」
4. ダウンロードした `.pbiviz` ファイルを選択

## 使い方

1. レポートに「テーブル」ビジュアルと本カスタムビジュアルを並べて配置
2. 本ビジュアルの「コピーする値」フィールドに、表示したい列をドラッグ
3. テーブルビジュアルで行をクリック → 本ビジュアルに値がテーブル形式で表示される
4. コピーしたい行の右端「コピー」ボタンをクリック → クリップボードにコピー完了

## コピーする列の指定

複数列がある場合、書式設定でコピー対象の列を絞り込めます。

| 設定値 | 動作 |
|-------|------|
| `0`（デフォルト） | 全列をタブ区切りでコピー |
| `1` | 1列目のみコピー |
| `2` | 2列目のみコピー |
| ※以降同様 | |

- ビジュアル上部のインフォバーに現在のコピー対象列名が表示されます
- コピー対象の列はヘッダーに「★」が付き、青くハイライトされます

**設定場所:** 書式設定ペイン →「表示設定」→「コピーする列番号」

## 機能一覧

- クロスフィルターによる選択行の自動受信
- テーブル形式で値を表示（列名ヘッダー・ゼブラストライプ）
- 各行の右端にコピーボタン
- コピー対象列をビジュアル上部のインフォバーに表示
- コピー成功時にボタンが「✓」に変わる（2秒後に戻る）

## Format Pane 設定

| カテゴリ | 設定項目 | デフォルト | 説明 |
|---------|---------|-----------|------|
| ボタン設定 | ボタンテキスト | コピー | ボタンのラベル |
| ボタン設定 | ボタン背景色 | #0078d4 | |
| ボタン設定 | ボタン文字色 | #ffffff | |
| 表示設定 | フォントサイズ | 14 | 10〜32px |
| 表示設定 | 区切り文字 | タブ | 全列コピー時の区切り（タブ / カンマ / パイプ） |
| 表示設定 | 値を表示する | オン | オフにするとボタンのみ表示 |
| 表示設定 | コピーする列番号 | 0 | 0=全列、1以上=指定列のみ |

## 技術仕様

- Power BI Visuals API v5.3.0
- TypeScript + Format Pane API v4
- クリップボード: `navigator.clipboard.writeText()` → `execCommand('copy')` フォールバック
- 外部サービスへの通信なし

## ソースからビルドする場合

```bash
npm install -g powerbi-visuals-tools
npm install
npm run package
```
